These are current-public posterior combo distributions; completion Monte Carlo sample counts are excluded. Normal contributes one exposure unit per observed decision.

At the smallest three-GPU workload, approximately 6197 fresh decisions would contribute about 6.77 million raw posterior units in the first iteration. With entropy horizon 250000 and reference interval 400000, the raw-clock arm crosses the entropy endpoint and roughly 16 reference thresholds at its first completed iteration boundary. Entropy is zero for subsequent training. One reference copy occurs at that boundary, even though the threshold counter advances many times. Larger workloads saturate the schedule immediately too.

This is a consequential sensitivity test, but it changes both schedules together and collapses many large multipliers into the same iteration-boundary behavior. It cannot by itself validate or reject the broader effective-hands hypothesis. Calibration should separate entropy and reference effects, inspect overshoot, and measure correlations of posterior-weighted combo contributions before claiming an independent-hands conversion. Batch-gradient noise probes do not measure all within-posterior correlations. No active arm uses a square-root exponent; legacy square-root summaries remain in telemetry, without calibrated evidential status.
